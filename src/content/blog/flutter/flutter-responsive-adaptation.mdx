# 响应式布局与多平台适配

Flutter 的核心价值之一是**一次编写，多平台运行**。然而手机屏幕与平板、桌面窗口的尺寸差异巨大，甚至折叠屏设备还能在运行中改变形态。如何让 UI 在不同尺寸下都保持良好的可用性和美观度？本章将系统讲解 Flutter 的响应式布局工具、多平台适配策略以及折叠屏等新兴设备的应对方案。

## 响应式与自适应的区别

在深入技术细节之前，先厘清两个常被混淆的概念：

| 概念 | 定义 | 示例 |
|------|------|------|
| **响应式** (Responsive) | 布局随屏幕尺寸变化而**动态调整**结构 | 手机端单列、平板端双列、桌面端三列 |
| **自适应** (Adaptive) | 根据平台特性**切换不同的实现** | iOS 用 Cupertino 风格，Android 用 Material 风格 |

Flutter 同时支持两者：响应式通过布局 Widget 和约束系统实现，自适应通过条件判断或平台检测实现。

## 获取屏幕信息：MediaQuery

**MediaQuery** 是 Flutter 中查询设备屏幕信息的入口，它以 InheritedWidget 的形式存在于 Widget 树中，子节点通过 `MediaQuery.of(context)` 访问。

### 常用属性

```dart
class MediaQueryDemo extends StatelessWidget {
  const MediaQueryDemo({super.key});

  @override
  Widget build(BuildContext context) {
    final mq = MediaQuery.of(context);

    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text('屏幕宽度: ${mq.size.width}'),
        Text('屏幕高度: ${mq.size.height}'),
        Text('设备像素比: ${mq.devicePixelRatio}'),
        Text('安全区顶部: ${mq.padding.top}'),    // 刘海屏/灵动岛
        Text('安全区底部: ${mq.padding.bottom}'),  // 底部手势条
        Text('方向: ${mq.orientation}'),           // portrait / landscape
        Text('文字缩放: ${mq.textScaler.scale(1)}'),
        Text('亮度模式: ${mq.platformBrightness}'), // light / dark
        Text('是否可访问: ${mq.accessibleNavigation}'),
      ],
    );
  }
}
```

### 安全区处理

现代手机普遍有刘海、挖孔、圆角和底部手势条。`SafeArea` Widget 自动处理这些：

```dart
class SafeAreaDemo extends StatelessWidget {
  const SafeAreaDemo({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      // 不使用 SafeArea 时内容可能重叠刘海
      body: SafeArea(
        // 可选：指定哪些边需要安全区
        minimum: const EdgeInsets.all(16),
        child: Column(
          children: [
            // 内容自动避开安全区
            Expanded(child: ListView(/* ... */)),
          ],
        ),
      ),
    );
  }
}
```

### 文字缩放适配

用户可能开启系统级字体放大，`textScaler` 反映了用户的设置：

```dart
Text(
  '正文内容',
  style: TextStyle(
    // 跟随系统文字缩放
    fontSize: 16 * MediaQuery.of(context).textScaler.scale(1),
  ),
)

// 或者限制最大缩放倍率，防止布局崩坏
final limitedScale = MediaQuery.of(context).textScaler.clamp(
  minScaleFactor: 0.8,
  maxScaleFactor: 1.5,
);
```

## LayoutBuilder：根据约束构建

**LayoutBuilder** 的核心优势在于：它不依赖屏幕尺寸，而是依赖**父容器传递下来的约束**（Constraints）。这意味着即使在屏幕内的一个局部区域，也可以根据可用空间决定布局策略。

```dart
class LayoutBuilderDemo extends StatelessWidget {
  const LayoutBuilderDemo({super.key});

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(
      builder: (context, constraints) {
        // constraints.maxWidth / maxHeight
        // constraints.minWidth / minHeight

        if (constraints.maxWidth < 600) {
          // 窄屏：单列布局
          return _buildMobileLayout();
        } else if (constraints.maxWidth < 1200) {
          // 中屏：双列布局
          return _buildTabletLayout();
        } else {
          // 宽屏：三列布局
          return _buildDesktopLayout();
        }
      },
    );
  }

  Widget _buildMobileLayout() {
    return ListView(children: const [
      Card(child: ListTile(title: Text('Item 1'))),
      Card(child: ListTile(title: Text('Item 2'))),
      Card(child: ListTile(title: Text('Item 3'))),
    ]);
  }

  Widget _buildTabletLayout() {
    return GridView.count(
      crossAxisCount: 2,
      children: const [
        Card(child: Center(child: Text('Item 1'))),
        Card(child: Center(child: Text('Item 2'))),
        Card(child: Center(child: Text('Item 3'))),
      ],
    );
  }

  Widget _buildDesktopLayout() {
    return GridView.count(
      crossAxisCount: 3,
      children: const [
        Card(child: Center(child: Text('Item 1'))),
        Card(child: Center(child: Text('Item 2'))),
        Card(child: Center(child: Text('Item 3'))),
      ],
    );
  }
}
```

## 断点系统与响应式工具

虽然可以用 `LayoutBuilder` 手写断点判断，但社区有更优雅的封装。Flutter 官方推荐的 `flutter_adaptive_scaffold` 包提供了更高级的响应式组件。

### 自定义断点常量

```dart
// lib/core/breakpoints.dart
class Breakpoints {
  static const double mobile = 0;
  static const double tablet = 600;
  static const double desktop = 1200;
}

enum ScreenType { mobile, tablet, desktop }

// 便捷扩展
extension BuildContextResponsive on BuildContext {
  ScreenType get screenType {
    final width = MediaQuery.of(this).size.width;
    if (width >= Breakpoints.desktop) return ScreenType.desktop;
    if (width >= Breakpoints.tablet) return ScreenType.tablet;
    return ScreenType.mobile;
  }

  bool get isMobile => screenType == ScreenType.mobile;
  bool get isTablet => screenType == ScreenType.tablet;
  bool get isDesktop => screenType == ScreenType.desktop;
}

// 使用
class AdaptivePage extends StatelessWidget {
  const AdaptivePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: context.isDesktop
          ? const DesktopLayout()
          : context.isTablet
              ? const TabletLayout()
              : const MobileLayout(),
    );
  }
}
```

### 响应式 Grid 封装

```dart
class ResponsiveGrid extends StatelessWidget {
  final List<Widget> children;
  const ResponsiveGrid({super.key, required this.children});

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(
      builder: (context, constraints) {
        int crossAxisCount;
        double childAspectRatio;

        if (constraints.maxWidth >= 1200) {
          crossAxisCount = 4;
          childAspectRatio = 1.5;
        } else if (constraints.maxWidth >= 800) {
          crossAxisCount = 3;
          childAspectRatio = 1.2;
        } else if (constraints.maxWidth >= 600) {
          crossAxisCount = 2;
          childAspectRatio = 1.0;
        } else {
          crossAxisCount = 1;
          childAspectRatio = 1.3;
        }

        return GridView.builder(
          gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
            crossAxisCount: crossAxisCount,
            childAspectRatio: childAspectRatio,
            crossAxisSpacing: 16,
            mainAxisSpacing: 16,
          ),
          itemCount: children.length,
          itemBuilder: (context, index) => children[index],
        );
      },
    );
  }
}
```

## 自适应导航模式

移动应用通常使用底部导航栏（BottomNavigationBar），而桌面/平板应用更适合侧边导航栏（NavigationRail）。Flutter 3.x 起提供了 `NavigationBar` 和 `NavigationRail` 两套组件，可以无缝切换：

```dart
class AdaptiveNavigation extends StatefulWidget {
  const AdaptiveNavigation({super.key});

  @override
  State<AdaptiveNavigation> createState() => _AdaptiveNavigationState();
}

class _AdaptiveNavigationState extends State<AdaptiveNavigation> {
  int _selectedIndex = 0;

  final _destinations = const [
    NavigationDestination(icon: Icon(Icons.home), label: '首页'),
    NavigationDestination(icon: Icon(Icons.search), label: '搜索'),
    NavigationDestination(icon: Icon(Icons.person), label: '我的'),
  ];

  final _pages = const [
    HomePage(),
    SearchPage(),
    ProfilePage(),
  ];

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(
      builder: (context, constraints) {
        // 宽屏用侧边导航，窄屏用底部导航
        if (constraints.maxWidth >= 600) {
          return Scaffold(
            body: Row(
              children: [
                NavigationRail(
                  selectedIndex: _selectedIndex,
                  onDestinationSelected: (index) {
                    setState(() => _selectedIndex = index);
                  },
                  destinations: const [
                    NavigationRailDestination(
                      icon: Icon(Icons.home),
                      label: Text('首页'),
                    ),
                    NavigationRailDestination(
                      icon: Icon(Icons.search),
                      label: Text('搜索'),
                    ),
                    NavigationRailDestination(
                      icon: Icon(Icons.person),
                      label: Text('我的'),
                    ),
                  ],
                  // 宽屏时展开标签
                  extended: constraints.maxWidth >= 800,
                ),
                const VerticalDivider(thickness: 1, width: 1),
                Expanded(child: _pages[_selectedIndex]),
              ],
            ),
          );
        }

        // 窄屏：底部导航
        return Scaffold(
          body: _pages[_selectedIndex],
          bottomNavigationBar: NavigationBar(
            selectedIndex: _selectedIndex,
            onDestinationSelected: (index) {
              setState(() => _selectedIndex = index);
            },
            destinations: _destinations,
          ),
        );
      },
    );
  }
}
```

## 折叠屏适配

折叠屏设备（如 Samsung Galaxy Z Fold、Pixel Fold）可以在折叠和展开状态之间切换。Flutter 提供了 `DisplayFeatureSubScreen` 和 `MediaQuery.displayFeatures` 来检测这些特性。

### 检测折叠状态

```dart
import 'package:flutter/services.dart';

class FoldableAwareWidget extends StatelessWidget {
  const FoldableAwareWidget({super.key});

  @override
  Widget build(BuildContext context) {
    final mediaQuery = MediaQuery.of(context);
    final displayFeatures = mediaQuery.displayFeatures;

    // 检测是否有铰链（hinge）或折叠区域
    final hasHinge = displayFeatures.any((f) =>
        f.type == DisplayFeatureType.hinge ||
        f.type == DisplayFeatureType.fold);

    // 获取折叠区域边界
    final hingeBounds = displayFeatures
        .where((f) => f.type == DisplayFeatureType.hinge)
        .map((f) => f.bounds);

    return Scaffold(
      body: hasHinge
          ? _buildDualPaneLayout(hingeBounds)
          : _buildSinglePaneLayout(),
    );
  }

  Widget _buildDualPaneLayout(Iterable<Rect> hingeBounds) {
    // 双屏布局：左侧列表，右侧详情
    return Row(
      children: [
        const Expanded(
          flex: 1,
          child: MasterList(),
        ),
        // 避开铰链区域
        if (hingeBounds.isNotEmpty)
          SizedBox(width: hingeBounds.first.width),
        const Expanded(
          flex: 1,
          child: DetailView(),
        ),
      ],
    );
  }

  Widget _buildSinglePaneLayout() {
    return const MasterList();
  }
}
```

## 桌面端特有适配

Flutter 桌面端（Windows/macOS/Linux）需要额外处理窗口大小调整、鼠标悬停状态和键盘快捷键。

### 鼠标悬停效果

```dart
class HoverButton extends StatefulWidget {
  final VoidCallback? onPressed;
  final Widget child;
  const HoverButton({super.key, this.onPressed, required this.child});

  @override
  State<HoverButton> createState() => _HoverButtonState();
}

class _HoverButtonState extends State<HoverButton> {
  bool _isHovered = false;

  @override
  Widget build(BuildContext context) {
    return MouseRegion(
      onEnter: (_) => setState(() => _isHovered = true),
      onExit: (_) => setState(() => _isHovered = false),
      child: GestureDetector(
        onTap: widget.onPressed,
        child: AnimatedContainer(
          duration: const Duration(milliseconds: 150),
          padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 8),
          decoration: BoxDecoration(
            color: _isHovered ? Colors.blue.shade100 : Colors.transparent,
            borderRadius: BorderRadius.circular(8),
          ),
          child: widget.child,
        ),
      ),
    );
  }
}
```

## 平台检测与条件编译

除了响应式布局，有时需要根据平台特性做不同实现：

```dart
import 'dart:io' show Platform;
import 'package:flutter/foundation.dart';

class PlatformAwareWidget extends StatelessWidget {
  const PlatformAwareWidget({super.key});

  @override
  Widget build(BuildContext context) {
    // kIsWeb 必须在 Platform.isX 之前检查
    if (kIsWeb) {
      return const WebSpecificWidget();
    }

    if (Platform.isIOS) {
      return const CupertinoStyleWidget();
    }

    if (Platform.isAndroid) {
      return const MaterialStyleWidget();
    }

    if (Platform.isMacOS || Platform.isWindows || Platform.isLinux) {
      return const DesktopSpecificWidget();
    }

    return const DefaultWidget();
  }
}
```

## 综合适配方案

一个成熟的 Flutter 应用通常将上述工具组合使用：

```dart
class AdaptiveApp extends StatelessWidget {
  const AdaptiveApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        body: SafeArea(
          child: LayoutBuilder(
            builder: (context, constraints) {
              // 1. 先根据断点确定整体架构
              if (constraints.maxWidth >= Breakpoints.desktop) {
                // 桌面端：侧边导航 + 主内容区 + 可选右侧面板
                return const DesktopScaffold();
              }

              if (constraints.maxWidth >= Breakpoints.tablet) {
                // 平板端：NavigationRail + 双 pane 布局
                return const TabletScaffold();
              }

              // 手机端：底部导航 + 单列布局
              return const MobileScaffold();
            },
          ),
        ),
      ),
    );
  }
}
```

## 总结

| 场景 | 推荐方案 |
|------|---------|
| 查询屏幕尺寸/方向 | `MediaQuery.of(context)` |
| 根据父容器约束布局 | `LayoutBuilder` |
| 根据方向调整列数 | `OrientationBuilder` |
| 安全区适配 | `SafeArea` |
| 导航模式切换 | `NavigationBar` ↔ `NavigationRail` |
| 折叠屏检测 | `MediaQuery.displayFeatures` |
| 桌面端悬停/快捷键 | `MouseRegion` + `CallbackShortcuts` |
| 平台条件编译 | `kIsWeb` / `Platform.isX` |

响应式布局的核心在于**约束驱动设计**——不依赖固定的像素值，而是根据可用空间动态决策。配合 Flutter 强大的声明式 UI 系统，适配多平台变得系统化且可维护。
