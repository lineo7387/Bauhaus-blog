# 自定义绘制与动画系统

Flutter 的声明式 UI 体系覆盖了绝大多数日常开发需求，但在某些场景下——如数据可视化图表、复杂游戏画面、特殊过渡效果——我们需要直接操控底层的绘制能力。Flutter 提供了**CustomPainter** 作为绘制扩展入口，配合强大的**动画系统**，可以创造出高度定制化的视觉体验。本文将完整覆盖自定义绘制原理、动画驱动机制以及 Hero 转场动画。

## CustomPainter：自定义绘制的核心

**CustomPainter** 是一个抽象类，继承它并实现 `paint` 和 `shouldRepaint` 方法，即可在 Flutter 的渲染流程中插入自定义绘图逻辑。

### 基础结构

```dart
import 'package:flutter/material.dart';

// 1. 继承 CustomPainter
class DemoPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    // 所有绘制逻辑写在这里
    final paint = Paint()
      ..color = Colors.blue
      ..strokeWidth = 4
      ..style = PaintingStyle.stroke;

    // 在画布中心画一个圆
    final center = Offset(size.width / 2, size.height / 2);
    final radius = size.width / 3;
    canvas.drawCircle(center, radius, paint);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) {
    // 返回 true 表示每次 rebuild 都重绘；返回 false 可复用缓存
    return false;
  }
}

// 2. 用 CustomPaint Widget 接入
class CustomPaintDemo extends StatelessWidget {
  const CustomPaintDemo({super.key});

  @override
  Widget build(BuildContext context) {
    return Center(
      child: SizedBox(
        width: 200,
        height: 200,
        child: CustomPaint(
          painter: DemoPainter(),
          // child 可选，绘制时 child 会覆盖在 painter 上层
          child: const Center(child: Text('Overlay')),
        ),
      ),
    );
  }
}
```

### Paint 对象配置详解

**Paint** 对象相当于绘图的画笔配置，支持丰富的样式属性：

```dart
final paint = Paint()
  ..color = Colors.red.withValues(alpha: 0.8)  // 颜色与透明度
  ..strokeWidth = 8.0                            // 描边宽度
  ..style = PaintingStyle.fill                   // fill 填充 / stroke 描边
  ..strokeCap = StrokeCap.round                  // 线帽样式
  ..strokeJoin = StrokeJoin.miter                // 线段连接样式
  ..blendMode = BlendMode.multiply               // 混合模式
  ..shader = LinearGradient(
        colors: [Colors.red, Colors.blue],
      ).createShader(Rect.fromLTRB(0, 0, 100, 100)); // 渐变着色器
```

## Canvas API：从几何到路径

**Canvas** 提供了完整的 2D 绘图 API，覆盖基本几何、路径、文字和图片。

### 基本几何绘制

```dart
@override
void paint(Canvas canvas, Size size) {
  final paint = Paint()..color = Colors.indigo;

  // 矩形
  canvas.drawRect(
    Rect.fromLTWH(20, 20, 100, 60),
    paint,
  );

  // 圆角矩形
  canvas.drawRRect(
    RRect.fromRectAndRadius(
      Rect.fromLTWH(20, 100, 100, 60),
      const Radius.circular(12),
    ),
    paint,
  );

  // 圆形
  canvas.drawCircle(const Offset(200, 50), 40, paint);

  // 椭圆
  canvas.drawOval(
    Rect.fromCenter(center: const Offset(200, 160), width: 80, height: 40),
    paint,
  );

  // 直线
  canvas.drawLine(
    const Offset(20, 200),
    const Offset(280, 200),
    paint..strokeWidth = 3..style = PaintingStyle.stroke,
  );
}
```

### Path：自由路径绘制

**Path** 允许创建任意复杂形状，支持子路径、贝塞尔曲线等高级特性：

```dart
@override
void paint(Canvas canvas, Size size) {
  final paint = Paint()
    ..color = Colors.teal
    ..style = PaintingStyle.fill;

  final path = Path()
    // 移动到起点
    ..moveTo(50, 200)
    // 二阶贝塞尔曲线（控制点 + 终点）
    ..quadraticBezierTo(150, 50, 250, 200)
    // 直线
    ..lineTo(250, 250)
    ..lineTo(50, 250)
    // 闭合路径
    ..close();

  canvas.drawPath(path, paint);

  // 绘制带箭头的路径
  final arrowPath = Path()
    ..moveTo(100, 100)
    ..lineTo(200, 100)
    ..lineTo(190, 90)
    ..moveTo(200, 100)
    ..lineTo(190, 110);

  canvas.drawPath(
    arrowPath,
    Paint()
      ..color = Colors.black
      ..strokeWidth = 3
      ..style = PaintingStyle.stroke,
  );
}
```

### 图表绘制实战：饼图

```dart
class PieChartPainter extends CustomPainter {
  final List<double> values;    // 各扇区数值
  final List<Color> colors;     // 各扇区颜色

  PieChartPainter({required this.values, required this.colors});

  @override
  void paint(Canvas canvas, Size size) {
    final total = values.reduce((a, b) => a + b);
    final center = Offset(size.width / 2, size.height / 2);
    final radius = size.width < size.height
        ? size.width / 2 - 20
        : size.height / 2 - 20;

    double startAngle = 0;

    for (int i = 0; i < values.length; i++) {
      final sweepAngle = (values[i] / total) * 2 * 3.14159;

      final paint = Paint()
        ..color = colors[i]
        ..style = PaintingStyle.fill;

      // drawArc: 绘制弧/扇形
      canvas.drawArc(
        Rect.fromCircle(center: center, radius: radius),
        startAngle,      // 起始弧度
        sweepAngle,      // 扫过弧度
        true,            // useCenter: true 画扇形，false 画弧
        paint,
      );

      startAngle += sweepAngle;
    }
  }

  @override
  bool shouldRepaint(covariant PieChartPainter oldDelegate) {
    // 数据变化时才重绘
    return oldDelegate.values != values || oldDelegate.colors != colors;
  }
}

// 使用
class PieChart extends StatelessWidget {
  const PieChart({super.key});

  @override
  Widget build(BuildContext context) {
    return CustomPaint(
      size: const Size(300, 300),
      painter: PieChartPainter(
        values: [30, 25, 20, 15, 10],
        colors: [Colors.red, Colors.blue, Colors.green, Colors.yellow, Colors.purple],
      ),
    );
  }
}
```

### 渐变与阴影

```dart
@override
void paint(Canvas canvas, Size size) {
  final rect = Rect.fromLTWH(20, 20, size.width - 40, size.height - 40);

  // 线性渐变
  final linearGradient = LinearGradient(
    begin: Alignment.topLeft,
    end: Alignment.bottomRight,
    colors: [Colors.blue.shade300, Colors.purple.shade400],
  );

  final paint = Paint()
    ..shader = linearGradient.createShader(rect)
    ..style = PaintingStyle.fill;

  canvas.drawRRect(
    RRect.fromRectAndRadius(rect, const Radius.circular(16)),
    paint,
  );

  // 径向渐变（模拟发光效果）
  final glowPaint = Paint()
    ..shader = RadialGradient(
      colors: [Colors.yellow.withValues(alpha: 0.6), Colors.transparent],
    ).createShader(Rect.fromCircle(
      center: Offset(size.width / 2, size.height / 2),
      radius: 100,
    ));

  canvas.drawCircle(
    Offset(size.width / 2, size.height / 2),
    100,
    glowPaint,
  );
}
```

## 动画系统：Tween 与 AnimationController

Flutter 的动画系统分为**隐式动画**（Implicit Animations，如 AnimatedContainer）和**显式动画**（Explicit Animations，需手动控制 AnimationController）。自定义绘制通常需要显式动画。

### AnimationController 基础

```dart
class SpinningCircle extends StatefulWidget {
  const SpinningCircle({super.key});

  @override
  State<SpinningCircle> createState() => _SpinningCircleState();
}

class _SpinningCircleState extends State<SpinningCircle>
    with SingleTickerProviderStateMixin {
  // AnimationController 需要 TickerProvider 来驱动每一帧
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(seconds: 2),
    )
      // 重复播放
      ..repeat();
  }

  @override
  void dispose() {
    _controller.dispose(); // 必须释放，防止内存泄漏
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    // AnimatedBuilder 监听动画值变化并重建
    return AnimatedBuilder(
      animation: _controller,
      builder: (context, child) {
        return CustomPaint(
          size: const Size(200, 200),
          painter: SpinPainter(_controller.value),
        );
      },
    );
  }
}

class SpinPainter extends CustomPainter {
  final double progress; // 0.0 ~ 1.0
  SpinPainter(this.progress);

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final paint = Paint()
      ..color = Colors.indigo
      ..strokeWidth = 8
      ..style = PaintingStyle.stroke;

    // 根据 progress 计算旋转角度
    final sweepAngle = progress * 2 * 3.14159;

    canvas.drawArc(
      Rect.fromCircle(center: center, radius: 60),
      0,
      sweepAngle,
      false,
      paint,
    );
  }

  @override
  bool shouldRepaint(covariant SpinPainter oldDelegate) {
    return oldDelegate.progress != progress;
  }
}
```

### Tween 插值动画

**Tween** 负责将 AnimationController 输出的 `0.0 ~ 1.0` 映射到任意目标区间：

```dart
class AnimatedBarChart extends StatefulWidget {
  const AnimatedBarChart({super.key});

  @override
  State<AnimatedBarChart> createState() => _AnimatedBarChartState();
}

class _AnimatedBarChartState extends State<AnimatedBarChart>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _animation;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 1500),
    );

    // Tween 将 0.0~1.0 映射为 0.0~300.0
    _animation = Tween<double>(begin: 0, end: 300).animate(
      // CurvedAnimation 添加缓动曲线
      CurvedAnimation(
        parent: _controller,
        curve: Curves.easeOutCubic,
      ),
    );

    _controller.forward(); // 正向播放一次
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _animation,
      builder: (context, child) {
        return CustomPaint(
          size: const Size(400, 350),
          painter: BarChartPainter(_animation.value),
        );
      },
    );
  }
}

class BarChartPainter extends CustomPainter {
  final double maxBarHeight;
  BarChartPainter(this.maxBarHeight);

  @override
  void paint(Canvas canvas, Size size) {
    final values = [0.6, 0.8, 0.4, 0.9, 0.7];
    final barWidth = 40.0;
    final spacing = 30.0;
    final startX = 30.0;

    for (int i = 0; i < values.length; i++) {
      final barHeight = values[i] * maxBarHeight;
      final x = startX + i * (barWidth + spacing);
      final y = size.height - barHeight - 30;

      final paint = Paint()
        ..color = Colors.primaries[i % Colors.primaries.length]
        ..style = PaintingStyle.fill;

      canvas.drawRRect(
        RRect.fromRectAndRadius(
          Rect.fromLTWH(x, y, barWidth, barHeight),
          const Radius.circular(4),
        ),
        paint,
      );
    }
  }

  @override
  bool shouldRepaint(covariant BarChartPainter oldDelegate) {
    return oldDelegate.maxBarHeight != maxBarHeight;
  }
}
```

### 复合 Tween：多属性同时动画

```dart
// 使用 TweenSequence 或同时驱动多个 Tween
late final Animation<Color?> _colorAnimation;
late final Animation<double> _sizeAnimation;
late final Animation<Offset> _positionAnimation;

@override
void initState() {
  super.initState();
  _controller = AnimationController(
    vsync: this,
    duration: const Duration(seconds: 2),
  );

  _colorAnimation = ColorTween(
    begin: Colors.red,
    end: Colors.blue,
  ).animate(_controller);

  _sizeAnimation = Tween<double>(begin: 50, end: 150).animate(
    CurvedAnimation(parent: _controller, curve: Curves.easeInOut),
  );

  _positionAnimation = Tween<Offset>(
    begin: Offset.zero,
    end: const Offset(100, 50),
  ).animate(_controller);

  _controller.forward();
}
```

### 交错动画：Staggered Animations

多个动画按时间差依次启动，可营造丰富的层次感：

```dart
class StaggeredDemo extends StatefulWidget {
  const StaggeredDemo({super.key});

  @override
  State<StaggeredDemo> createState() => _StaggeredDemoState();
}

class _StaggeredDemoState extends State<StaggeredDemo>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late List<Animation<double>> _animations;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 2000),
    );

    // 5 个元素，每个间隔 200ms 启动
    _animations = List.generate(5, (i) {
      final start = i * 0.15;
      final end = start + 0.6;
      return Tween<double>(begin: 0, end: 1).animate(
        CurvedAnimation(
          parent: _controller,
          // Interval 限制动画在总时长中的播放区间
          curve: Interval(start.clamp(0, 1), end.clamp(0, 1),
              curve: Curves.easeOutBack),
        ),
      );
    });

    _controller.forward();
  }

  @override
  Widget build(BuildContext context) {
    return Row(
      mainAxisAlignment: MainAxisAlignment.center,
      children: _animations.map((anim) {
        return AnimatedBuilder(
          animation: anim,
          builder: (context, child) {
            return Transform.scale(
              scale: anim.value,
              child: Container(
                width: 40,
                height: 40,
                margin: const EdgeInsets.all(4),
                decoration: const BoxDecoration(
                  color: Colors.indigo,
                  shape: BoxShape.circle,
                ),
              ),
            );
          },
        );
      }).toList(),
    );
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }
}
```

## Hero 动画与页面转场

**Hero** 动画是 Flutter 中最直观的共享元素转场效果：两个页面间同名的 Hero Widget 会在路由切换时自动执行平滑的位移和形变动画。

### Hero 基础用法

```dart
// 页面 A：缩略图
class GalleryPage extends StatelessWidget {
  const GalleryPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Gallery')),
      body: GridView.builder(
        gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
          crossAxisCount: 2,
        ),
        itemCount: 10,
        itemBuilder: (context, index) {
          return GestureDetector(
            onTap: () {
              // 导航到详情页，Hero 动画自动触发
              Navigator.push(
                context,
                MaterialPageRoute(
                  builder: (_) => DetailPage(imageId: 'image_$index'),
                ),
              );
            },
            child: Hero(
              // tag 必须全局唯一，用于匹配两个页面的 Hero
              tag: 'image_$index',
              child: ClipRRect(
                borderRadius: BorderRadius.circular(8),
                child: Image.network(
                  'https://picsum.photos/400?random=$index',
                  fit: BoxFit.cover,
                ),
              ),
            ),
          );
        },
      ),
    );
  }
}

// 页面 B：大图详情
class DetailPage extends StatelessWidget {
  final String imageId;
  const DetailPage({super.key, required this.imageId});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Colors.black,
      body: Center(
        child: Hero(
          tag: imageId, // tag 必须与页面 A 一致
          child: InteractiveViewer(
            // 支持手势缩放
            child: Image.network(
              'https://picsum.photos/800?random=${imageId.split("_").last}',
              fit: BoxFit.contain,
            ),
          ),
        ),
      ),
    );
  }
}
```

### 自定义 Hero 飞行路径

### 页面转场动画

除了 Hero，Flutter 还支持自定义路由的进入/退出动画：

```dart
// 自定义页面转场：从右滑入
class SlidePageRoute<T> extends PageRouteBuilder<T> {
  final Widget child;

  SlidePageRoute({required this.child})
      : super(
          pageBuilder: (context, animation, secondaryAnimation) => child,
          transitionsBuilder: (context, animation, secondaryAnimation, child) {
            const begin = Offset(1.0, 0.0); // 从右侧进入
            const end = Offset.zero;
            const curve = Curves.easeInOutCubic;

            final tween = Tween(begin: begin, end: end)
                .chain(CurveTween(curve: curve));

            return SlideTransition(
              position: animation.drive(tween),
              child: child,
            );
          },
          transitionDuration: const Duration(milliseconds: 400),
        );
}

// 使用自定义转场
Navigator.push(context, SlidePageRoute(child: const NextPage()));
```

## 综合案例：脉冲波纹效果

将 CustomPainter 与 AnimationController 结合，实现一个常见的加载/涟漪效果：

```dart
class RippleEffect extends StatefulWidget {
  const RippleEffect({super.key});

  @override
  State<RippleEffect> createState() => _RippleEffectState();
}

class _RippleEffectState extends State<RippleEffect>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(seconds: 2),
    )..repeat();
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _controller,
      builder: (context, child) {
        return CustomPaint(
          size: const Size(300, 300),
          painter: RipplePainter(_controller.value),
        );
      },
    );
  }
}

class RipplePainter extends CustomPainter {
  final double progress;
  RipplePainter(this.progress);

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final maxRadius = size.width / 2;

    // 绘制 3 层波纹，每圈相位差 1/3
    for (int i = 0; i < 3; i++) {
      final rippleProgress = (progress + i * 0.33) % 1.0;
      final radius = rippleProgress * maxRadius;
      final alpha = ((1 - rippleProgress) * 255).toInt();

      final paint = Paint()
        ..color = Colors.blue.withValues(alpha: alpha / 255)
        ..style = PaintingStyle.stroke
        ..strokeWidth = 3;

      canvas.drawCircle(center, radius, paint);
    }

    // 中心圆点
    canvas.drawCircle(
      center,
      8,
      Paint()..color = Colors.blue,
    );
  }

  @override
  bool shouldRepaint(covariant RipplePainter oldDelegate) {
    return oldDelegate.progress != progress;
  }
}
```

## 总结

| 能力 | 核心类/Widget | 关键要点 |
|------|-------------|----------|
| 自定义绘制 | `CustomPainter` + `CustomPaint` | 实现 `paint` 与 `shouldRepaint`，控制重绘时机 |
| 几何绘制 | `Canvas.drawCircle/Rect/Arc` | 掌握 Rect、Offset、RRect 等几何对象 |
| 路径绘制 | `Path` + `drawPath` | 贝塞尔曲线、子路径、close 闭合 |
| 动画驱动 | `AnimationController` + `Ticker` | 必须 dispose，配合 `AnimatedBuilder` 消费 |
| 插值映射 | `Tween<T>` + `CurvedAnimation` | 支持 double、Color、Offset、Size 等多种类型 |
| 共享元素 | `Hero` | tag 全局唯一，支持自定义 flightShuttleBuilder |
| 页面转场 | `PageRouteBuilder` | 组合 SlideTransition、FadeTransition、ScaleTransition |

掌握自定义绘制与动画后，Flutter 的视觉天花板几乎完全打开。无论是复杂图表、游戏画面还是精致的转场效果，都可以通过这些底层 API 精确实现。
