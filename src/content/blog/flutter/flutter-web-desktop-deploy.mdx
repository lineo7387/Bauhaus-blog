# Flutter Web、桌面端与发布部署

Flutter 的跨平台能力不仅限于移动设备，它同样支持 **Web** 和**桌面端**（Windows、macOS、Linux）。但每个平台都有其独特的渲染策略、适配要点和发布流程。本章将从 Web 渲染模式对比开始，逐步覆盖桌面端适配，最终完成各平台的发布部署。

## Flutter Web 渲染模式

Flutter Web 支持两种渲染引擎：**CanvasKit** 和 **HTML**。理解两者的差异是 Web 部署的第一步。

| 特性 | CanvasKit | HTML |
|------|-----------|------|
| 渲染方式 | WebAssembly + WebGL Skia | CSS + DOM + Canvas 2D |
| 包体积 | 较大（~2.8MB WASM） | 较小（~1MB JS） |
| 性能 | 高（接近原生） | 中（复杂场景可能掉帧） |
| 文本渲染 | 与移动端一致 | 依赖浏览器字体栈 |
| 插件支持 | 完整 | 部分受限 |
| 首屏加载 | 较慢 | 较快 |
| 推荐场景 | 复杂应用、游戏、图表 | 内容展示、简单交互 |

### 指定渲染模式

```bash
# CanvasKit（默认，适合复杂应用）
flutter build web --web-renderer canvaskit

# HTML（轻量，适合内容型网站）
flutter build web --web-renderer html

# 自动模式：移动端 HTML，桌面端 CanvasKit
flutter build web --web-renderer auto
```

### Web 适配要点

```dart
import 'package:flutter/foundation.dart' show kIsWeb;
import 'package:universal_html/html.dart' as html;

class WebAdapter {
  /// 检测是否在浏览器中运行
  static bool get isWeb => kIsWeb;

  /// 修改页面标题（仅在 Web 有效）
  static void setPageTitle(String title) {
    if (kIsWeb) {
      html.document.title = title;
    }
  }

  /// 修改 URL（用于 SEO 友好路由）
  static void setUrlPath(String path) {
    if (kIsWeb) {
      html.window.history.pushState(null, '', path);
    }
  }

  /// 监听浏览器后退按钮
  static void onPopState(void Function(String path) callback) {
    if (kIsWeb) {
      html.window.onPopState.listen((event) {
        callback(html.window.location.pathname ?? '/');
      });
    }
  }

  /// 检测用户代理
  static String? get userAgent {
    if (kIsWeb) {
      return html.window.navigator.userAgent;
    }
    return null;
  }
}
```

### Web SEO 优化

Flutter Web 是 SPA（单页应用），对搜索引擎不够友好。可通过以下方式改善：

```dart
// 1. 使用 go_router 配合 URL 策略
import 'package:flutter_web_plugins/url_strategy.dart';

void main() {
  // 移除 URL 中的 #（hash 模式 → path 模式）
  usePathUrlStrategy();
  runApp(const MyApp());
}

// 2. 动态更新 meta 标签
void updateMetaTags({String? title, String? description}) {
  if (kIsWeb) {
    if (title != null) {
      html.document.title = title;
    }
    if (description != null) {
      final meta = html.document.querySelector('meta[name="description"]')
          as html.MetaElement?;
      if (meta != null) {
        meta.content = description;
      }
    }
  }
}
```

### 桌面端特定 API

```dart
import 'package:flutter/material.dart';
import 'package:window_manager/window_manager.dart'; // 第三方包

class DesktopWindowManager {
  /// 初始化窗口管理
  static Future<void> initialize() async {
    await windowManager.ensureInitialized();

    WindowOptions windowOptions = const WindowOptions(
      size: Size(1280, 800),
      center: true,
      minimumSize: Size(800, 600),
      title: 'My Flutter Desktop App',
    );

    await windowManager.waitUntilReadyToShow(windowOptions, () async {
      await windowManager.show();
      await windowManager.focus();
    });
  }

  /// 设置全屏
  static Future<void> setFullScreen(bool full) async {
    await windowManager.setFullScreen(full);
  }

  /// 最小化到托盘
  static Future<void> hide() async {
    await windowManager.hide();
  }
}
```

```dart
import 'package:file_selector/file_selector.dart';

class FileService {
  /// 打开文件选择器
  static Future<XFile?> pickFile() async {
    const typeGroup = XTypeGroup(
      label: 'images',
      extensions: ['jpg', 'png', 'gif'],

    }
  }
```

## Android 发布

### 应用签名

```bash
# 1. 生成密钥库
keytool -genkey -v -keystore ~/upload-keystore.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias upload

# 2. 创建 key.properties 文件
# android/key.properties
storePassword=your_store_password
keyPassword=your_key_password
keyAlias=upload
storeFile=/Users/yourname/upload-keystore.jks
```

### Gradle 配置

```gradle
// android/app/build.gradle
android {
    // ...

    signingConfigs {
        release {
            def keystoreProperties = new Properties()
            def keystorePropertiesFile = rootProject.file('key.properties')
            if (keystorePropertiesFile.exists()) {
                keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
            }

            keyAlias keystoreProperties['keyAlias']
            keyPassword keystoreProperties['keyPassword']
            storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
            storePassword keystoreProperties['storePassword']
        }
    }

    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled true
            shrinkResources true
            proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro'
        }
    }
}
```

## iOS 发布

### 配置签名

在 Xcode 中配置：

1. 打开 `ios/Runner.xcworkspace`
2. 选择 Runner target → Signing & Capabilities
3. 选择你的 Apple Developer Team
4. 确保 Bundle Identifier 全局唯一

或使用命令行：

```bash
# 安装 CocoaPods 依赖
cd ios && pod install

# 构建 iOS
flutter build ios --release
```

### 构建 IPA

```bash
# 导出 IPA（用于 TestFlight 或 AdHoc 分发）
flutter build ipa --release

# 输出: build/ios/ipa/
```

### App Store 提交

```bash
# 方式 1：Xcode Organizer
# 打开 Xcode → Window → Organizer → 选择 Archive → Distribute App

# 方式 2：命令行上传
xcrun altool --upload-app \
  --type ios \
  --file build/ios/ipa/app.ipa \
  --apiKey YOUR_API_KEY \
  --apiIssuer YOUR_ISSUER_ID
```

### iOS 隐私清单（Privacy Manifest）

iOS 17+ 要求提交隐私清单文件：

```xml
<!-- ios/Runner/PrivacyInfo.xcprivacy -->

    <key>NSPrivacyAccessedAPITypes</key>
```

GitHub Actions 配置：

```yaml
# .github/workflows/deploy-web.yml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.27.x'
      - run: flutter pub get
      - run: flutter build web --release
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./build/web
```

```bash

flutter build macos --release

# 输出: build/macos/Build/Products/Release/YourApp.app
```

签名与公证：

```bash
# 1. 签名应用
codesign --deep --force --verify --verbose \
  --sign "Developer ID Application: Your Name" \
  YourApp.app

# 2. 打包 DMG
create-dmg \
  --volname "YourApp Installer" \
  --window-size 800 400 \
  --icon-size 100 \
  --app-drop-link 600 185 \
  "YourApp.dmg" \
  "build/macos/Build/Products/Release/YourApp.app"

# 3. 公证（Notarization）用于分发
codesign --deep --force --options runtime \
  --sign "Developer ID Application: Your Name" \
  YourApp.app

xcrun altool --notarize-app \
  --primary-bundle-id "com.yourcompany.app" \
  --username "your@email.com" \
  --password "@keychain:AC_PASSWORD" \
  --file YourApp.dmg
```

## 自动化构建与 CI/CD

### GitHub Actions 完整配置

```yaml
# .github/workflows/build.yml
name: Build All Platforms

on:
  push:
    tags: ['v*']

jobs:
  build-android:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4

          distribution: 'temurin'

          flutter-version: '3.27.x'
      - run: flutter pub get
      - run: echo "${{ secrets.KEYSTORE_BASE64 }}" | base64 -d > android/app/keystore.jks
      - run: flutter build appbundle --release
      - uses: actions/upload-artifact@v4
        with:
          name: android-aab
          path: build/app/outputs/bundle/release/*.aab

  build-ios:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.27.x'
      - run: flutter pub get
      - run: flutter build ios --release --no-codesign
      - run: cd build/ios/iphoneos && mkdir Payload && cp -r Runner.app Payload/
      - run: cd build/ios/iphoneos && zip -r app.ipa Payload
      - uses: actions/upload-artifact@v4
        with:
          name: ios-ipa
          path: build/ios/iphoneos/app.ipa

    runs-on: ubuntu-latest
```

## 总结

| 平台 | 构建命令 | 打包格式 | 发布渠道 |
|------|---------|---------|---------|
| Android | `flutter build appbundle` | AAB | Google Play、国内应用商店 |
| iOS | `flutter build ipa` | IPA | App Store、TestFlight |
| Web | `flutter build web` | 静态文件 | GitHub Pages、Firebase、Vercel |
| Windows | `flutter build windows` | EXE/MSIX | Microsoft Store、独立分发 |
| macOS | `flutter build macos` | APP/DMG | Mac App Store、独立分发 |
| Linux | `flutter build linux` | 可执行文件 | Snap Store、独立分发 |

Flutter 的跨平台优势在发布阶段体现得淋漓尽致：一套代码，六端输出。掌握各平台的构建与发布流程后，Flutter 应用的交付范围将大大扩展。
