# 事件处理与表单交互

用户交互是应用的核心。Flutter 提供了丰富的事件处理机制，从简单的点击响应到复杂的手势识别，以及完善的表单验证体系。本文将系统讲解 Flutter 中的事件处理和表单交互技术。

## 基础点击事件

### GestureDetector（手势检测器）

**GestureDetector** 是最通用的事件处理 Widget，支持多种手势：

```dart
GestureDetector(
  onTap: () => print('单击'),
  onDoubleTap: () => print('双击'),
  onLongPress: () => print('长按'),
  onTapDown: (details) => print('按下: ${details.localPosition}'),
  onTapUp: (details) => print('抬起: ${details.localPosition}'),
  onTapCancel: () => print('取消'),
  child: Container(
    width: 200,
    height: 100,
    color: Colors.blue,
    child: Center(child: Text('点击我')),
  ),
)
```

### InkWell 与 InkResponse

**InkWell** 在 GestureDetector 的基础上增加了**水波纹（Ripple）效果**，符合 Material Design 规范：

```dart
InkWell(
  onTap: () => print('点击'),
  // 自定义水波纹颜色
  splashColor: Colors.blue.withValues(alpha: 0.3),
  // 高亮颜色
  highlightColor: Colors.blue.withValues(alpha: 0.1),
  // 圆角裁剪
  borderRadius: BorderRadius.circular(12),
  child: Container(
    padding: EdgeInsets.all(16),
    child: Text('带波纹的按钮'),
  ),
)
```

> **注意**：InkWell 的水波纹效果需要在 Material 组件内部才能正常显示。如果放在 Container 等普通 Widget 上，波纹可能被裁剪。解决方法是使用 **Ink** 或将 InkWell 作为 Card 等 Material 组件的子组件。

### 按钮组件

Flutter 提供多种预置按钮，每种有不同的视觉风格：

```dart
// 填充按钮（最常用）
ElevatedButton(
  onPressed: () => print('点击'),
  style: ElevatedButton.styleFrom(
    backgroundColor: Colors.blue,
    foregroundColor: Colors.white,
    padding: EdgeInsets.symmetric(horizontal: 24, vertical: 12),
    shape: RoundedRectangleBorder(
      borderRadius: BorderRadius.circular(8),
    ),
  ),
  child: Text('ElevatedButton'),
)

// 文本按钮（无背景）
TextButton(
  onPressed: () => print('点击'),
  child: Text('TextButton'),
)

// 描边按钮
OutlinedButton(
  onPressed: () => print('点击'),
  style: OutlinedButton.styleFrom(
    side: BorderSide(color: Colors.blue),
  ),
  child: Text('OutlinedButton'),
)

// 图标按钮
IconButton(
  onPressed: () => print('点击'),
  icon: Icon(Icons.favorite),
  color: Colors.red,
)

// 带图标的填充按钮
ElevatedButton.icon(
  onPressed: () => print('点击'),
  icon: Icon(Icons.send),
  label: Text('发送'),
)
```

| 按钮类型 | 视觉效果 | 适用场景 |
|---------|---------|---------|
| ElevatedButton | 有阴影的填充按钮 | 主要操作 |
| TextButton | 纯文本，无背景 | 次要操作、工具栏 |
| OutlinedButton | 带边框，透明背景 | 可选操作 |
| IconButton | 圆形图标按钮 | 工具栏、紧凑空间 |

### 手势冲突与竞争

当多个 GestureDetector 嵌套时，会发生**手势竞争**：

```dart
// 外层 GestureDetector
GestureDetector(
  onTap: () => print('外层点击'),
  // 控制手势如何参与竞争
  behavior: HitTestBehavior.translucent,
  child: Container(
    color: Colors.blue.withValues(alpha: 0.3),
    child: Center(
      // 内层 GestureDetector
      child: GestureDetector(
        onTap: () => print('内层点击'),
        child: Container(
          width: 100,
          height: 100,
          color: Colors.red,
        ),
      ),
    ),
  ),
)
```

**HitTestBehavior 三种模式**：

| 模式 | 行为 | 适用场景 |
|------|------|---------|
| `deferToChild` | 命中测试交给子组件（默认） | 子组件优先响应 |
| `opaque` | 当前组件不透明，阻挡子组件 | 需要拦截所有事件 |
| `translucent` | 允许子组件和父组件都响应 | 需要多层同时接收事件 |

### 原始指针事件

对于需要精确控制触摸的场景，可以使用原始指针事件：

```dart
Listener(
  onPointerDown: (event) => print('按下: ${event.position}'),
  onPointerMove: (event) => print('移动: ${event.delta}'),
  onPointerUp: (event) => print('抬起'),
  child: Container(
    width: 300,
    height: 300,
    color: Colors.grey,
  ),
)
```

> **Listener vs GestureDetector**：Listener 接收所有原始指针事件，没有手势识别逻辑；GestureDetector 会在收到一系列原始事件后，识别出具体的手势类型（如 tap、drag）再回调。

## 文本输入：TextField

### 基本使用

```dart
TextField(
  // 控制器：用于读取和设置文本
  controller: _textController,
  // 装饰：边框、标签、提示文字等
  decoration: InputDecoration(
    labelText: '用户名',
    hintText: '请输入用户名',
    prefixIcon: Icon(Icons.person),
    border: OutlineInputBorder(),
    // 聚焦时的边框
    focusedBorder: OutlineInputBorder(
      borderSide: BorderSide(color: Colors.blue, width: 2),
    ),
  ),
  // 键盘类型
  keyboardType: TextInputType.text,
  // 是否为密码
  obscureText: false,
  // 输入格式限制
  inputFormatters: [
    LengthLimitingTextInputFormatter(20),  // 最大长度
  ],
  // 文本变化回调
  onChanged: (value) => print('变化: $value'),
  // 提交回调
  onSubmitted: (value) => print('提交: $value'),
)
```

### TextEditingController

**TextEditingController** 是控制 TextField 的核心工具：

```dart
class _InputDemoState extends State<InputDemo> {
  final _usernameController = TextEditingController();
```

### 焦点控制

```dart
class _FocusDemoState extends State<FocusDemo> {
  final _usernameFocus = FocusNode();
  final _passwordFocus = FocusNode();

  @override
  void dispose() {
    _usernameFocus.dispose();
    _passwordFocus.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        TextField(
          focusNode: _usernameFocus,
          decoration: InputDecoration(labelText: '用户名'),
          // 回车跳转到密码框
          textInputAction: TextInputAction.next,
          onSubmitted: (_) {
            FocusScope.of(context).requestFocus(_passwordFocus);
          },
        ),
        TextField(
          focusNode: _passwordFocus,
          decoration: InputDecoration(labelText: '密码'),
          obscureText: true,
          // 回车提交
          textInputAction: TextInputAction.done,
          onSubmitted: (_) => _submit(),
        ),
      ],
    );
  }

  void _submit() {
    // 收起键盘
    FocusScope.of(context).unfocus();
    print('提交表单');
  }
}
```

## 表单验证：Form

### Form 与 TextFormField

**Form** 组件配合 **TextFormField** 可以实现完整的表单验证流程：

```dart
class _RegisterFormState extends State<RegisterForm> {
  // GlobalKey 用于访问 Form 状态
  final _formKey = GlobalKey<FormState>();
  final _passwordController = TextEditingController();

  String _username = '';
  String _email = '';
  String _password = '';

  @override
  void dispose() {
    _passwordController.dispose();
    super.dispose();
  }

  void _submit() {
    // 触发表单验证
    if (_formKey.currentState!.validate()) {
      // 保存表单数据
      _formKey.currentState!.save();
      print('注册: $_username, $_email');
    }
  }

  @override
  Widget build(BuildContext context) {
    return Form(
      key: _formKey,
      child: Column(
        children: [
          TextFormField(
            decoration: InputDecoration(
              labelText: '用户名',
              prefixIcon: Icon(Icons.person),
            ),
            // 验证器
            validator: (value) {
              if (value == null || value.isEmpty) {
                return '用户名不能为空';
              }
              if (value.length < 3) {
                return '用户名至少 3 个字符';
              }
              return null;  // 验证通过
            },
            onSaved: (value) => _username = value!,
          ),
          SizedBox(height: 16),
          TextFormField(
            decoration: InputDecoration(
              labelText: '邮箱',
              prefixIcon: Icon(Icons.email),
            ),
            keyboardType: TextInputType.emailAddress,
            validator: (value) {
              if (value == null || value.isEmpty) {
                return '邮箱不能为空';
              }
              // 简单的邮箱正则验证
              final emailRegex = RegExp(r'^[^@]+@[^@]+\.[^@]+');
              if (!emailRegex.hasMatch(value)) {
                return '请输入有效的邮箱地址';
              }
              return null;
            },
            onSaved: (value) => _email = value!,
          ),
          SizedBox(height: 16),
          TextFormField(
            controller: _passwordController,
            decoration: InputDecoration(
              labelText: '密码',
              prefixIcon: Icon(Icons.lock),
            ),
            obscureText: true,
            validator: (value) {
              if (value == null || value.length < 6) {
                return '密码至少 6 位';
              }
              return null;
            },
            onSaved: (value) => _password = value!,
          ),
          SizedBox(height: 16),
          TextFormField(
            decoration: InputDecoration(
              labelText: '确认密码',
              prefixIcon: Icon(Icons.lock_outline),
            ),
            obscureText: true,
            validator: (value) {
              if (value != _passwordController.text) {
                return '两次输入的密码不一致';
              }
              return null;
            },
          ),
          SizedBox(height: 24),
          SizedBox(
            width: double.infinity,
            child: ElevatedButton(
              onPressed: _submit,
              child: Text('注册'),
            ),
          ),
        ],
      ),
    );
  }
}
```

```dart
class _LoadingButtonState extends State<LoadingButton> {
  bool _isLoading = false;

  Future<void> _handlePress() async {
    setState(() => _isLoading = true);

    // 模拟网络请求
```

## 综合示例：登录页面

下面是一个完整的登录页面，综合运用本文介绍的所有技术：

```dart
class LoginPage extends StatefulWidget {
  const LoginPage({super.key});

  @override
  State<LoginPage> createState() => _LoginPageState();
}

class _LoginPageState extends State<LoginPage> {
  final _formKey = GlobalKey<FormState>();
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();
  bool _isLoading = false;
  bool _obscurePassword = true;

  @override
  void dispose() {
    _emailController.dispose();
    _passwordController.dispose();
    super.dispose();
  }

  Future<void> _login() async {
    if (!_formKey.currentState!.validate()) return;

    setState(() => _isLoading = true);
    FocusScope.of(context).unfocus();

    // 模拟登录请求
    await Future.delayed(Duration(seconds: 2));

    if (mounted) {
      setState(() => _isLoading = false);
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('登录成功！')),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: SafeArea(
        child: Padding(
          padding: EdgeInsets.all(24),
          child: Form(
            key: _formKey,
            child: Column(
              mainAxisAlignment: MainAxisAlignment.center,
              crossAxisAlignment: CrossAxisAlignment.stretch,
              children: [
                // Logo 区域
                Icon(
                  Icons.flutter_dash,
                  size: 80,
                  color: Theme.of(context).primaryColor,
                ),
                SizedBox(height: 32),
                Text(
                  '欢迎登录',
                  style: Theme.of(context).textTheme.headlineMedium,
                  textAlign: TextAlign.center,
                ),
                SizedBox(height: 32),
                // 邮箱输入
                TextFormField(
                  controller: _emailController,
                  keyboardType: TextInputType.emailAddress,
                  textInputAction: TextInputAction.next,
                  decoration: InputDecoration(
                    labelText: '邮箱',
                    prefixIcon: Icon(Icons.email),
                    border: OutlineInputBorder(),
                  ),
                  validator: (value) {
                    if (value?.isEmpty ?? true) return '请输入邮箱';
                    if (!value!.contains('@')) return '邮箱格式不正确';
                    return null;
                  },
                ),
                SizedBox(height: 16),
                // 密码输入
                TextFormField(
                  controller: _passwordController,
                  obscureText: _obscurePassword,
                  textInputAction: TextInputAction.done,
                  decoration: InputDecoration(
                    labelText: '密码',
                    prefixIcon: Icon(Icons.lock),
                    border: OutlineInputBorder(),
                    suffixIcon: IconButton(
                      icon: Icon(
                        _obscurePassword
                            ? Icons.visibility_off
                            : Icons.visibility,
                      ),
                      onPressed: () => setState(
                        () => _obscurePassword = !_obscurePassword,
                      ),
                    ),
                  ),
                  validator: (value) {
                    if (value?.isEmpty ?? true) return '请输入密码';
                    if (value!.length < 6) return '密码至少 6 位';
                    return null;
                  },
                  onFieldSubmitted: (_) => _login(),
                ),
                SizedBox(height: 24),
                // 登录按钮
                ElevatedButton(
                  onPressed: _isLoading ? null : _login,
                  style: ElevatedButton.styleFrom(
                    padding: EdgeInsets.symmetric(vertical: 16),
                  ),
                  child: _isLoading
                      ? SizedBox(
                          height: 20,
                          width: 20,
                          child: CircularProgressIndicator(strokeWidth: 2),
                        )
                      : Text('登录'),
                ),
                SizedBox(height: 16),
                // 辅助按钮
                Row(
                  mainAxisAlignment: MainAxisAlignment.center,
                  children: [
                    TextButton(
                      onPressed: () {},
                      child: Text('忘记密码？'),
                    ),
                    Text('·'),
                    TextButton(
                      onPressed: () {},
                      child: Text('注册账号'),
                    ),
                  ],
                ),
              ],
            ),
          ),
        ),
      ),
    );
  }
}
```

## 小结

3. **文本输入**：TextField 与 TextEditingController 的配合，焦点控制
4. **表单验证**：Form + TextFormField + validator 的完整验证流程
5. **交互反馈**：加载状态、开关、复选框、滑块等状态驱动组件

掌握这些交互技术后，你就能构建功能完整、用户体验良好的表单界面了。基础知识篇到此结束，接下来将进入**进阶技能**的学习。
